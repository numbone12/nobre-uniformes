Crie um aplicativo web completo e responsivo (PWA) para a empresa Nobre Uniformes, com visual moderno e limpo, utilizando azul médio, preto e branco como cores principais. A logo (uma torre azul com o nome "Nobre Uniformes" em branco) deve estar visível no topo.  O sistema deve funcionar como um painel de ordens de serviço para estamparia, com login, cadastro de usuários, funções específicas, anexos, controle financeiro (restrito ao administrador) e assinatura digital de etapas de produção.  🔐 1. Tela de Login (com fundo azul médio) Campos: E-mail, Senha  Botões: Entrar, Cadastrar-se, Esqueci minha senha  Login redireciona conforme a função do usuário (Administrador ou Equipe)  👤 2. Cadastro de Usuário Campos: Nome completo, E-mail, Senha, Confirmar senha, Função (Administrador, Corte, Costureira, Estampador)  Somente o administrador pode aprovar e ativar os usuários após o cadastro  🔑 3. Recuperação de Senha Campo: E-mail  Simulação de envio de link para redefinição de senha  🧭 4. Menu Principal após Login Nova Ordem (somente para administrador)  Histórico de Ordens  Confirmações Pendentes  Dashboard Financeiro (somente para administrador)  Gerenciar Usuários (somente para administrador)  Perfil / Sair  📝 5. Formulário de Nova Ordem de Serviço (Administrador) Nome do Cliente  Nome da Estampa  Tamanhos Masculinos/Femininos: PP, P, M, G, GG, XGG, XXGG (com campo de quantidade para cada)  Tamanhos Infantis: 2, 4, 6, 8, 10, 12 (com campo de quantidade)  Modelos (checkbox múltiplos): Raglan, Malha PV, Algodão, Dry Fit, Padrão, Regata, Camisa Polo  Descrição da arte  Upload de imagem (foto ou print da estampa)  Valor unitário da camisa (campo visível apenas para o administrador)  Cálculo automático da quantidade total × valor unitário = valor total (somente o administrador vê)  Data de entrada e data prevista de entrega  📂 6. Histórico de Ordens Lista de ordens com cliente, estampa, datas e status  Clique para visualizar todos os detalhes da ordem  Todos os usuários podem acessar e visualizar as ordens cadastradas  ✅ 7. Confirmação de Etapas (Assinatura virtual) Cada usuário só vê a etapa correspondente à sua função:  Corte: botão “Confirmar corte feito”  Costureira: botão “Confirmar costura feita”  Estampador: botão “Confirmar estampa feita”  Ao clicar, o sistema registra nome, função e data/hora como assinatura virtual  💰 8. Dashboard Financeiro (Somente Administrador) Tabela com:  Lista de ordens  Quantidade total de camisas por ordem  Valor unitário e valor total  Filtros por período e cliente  Gráficos de controle financeiro (opcional)  👑 9. Painel do Administrador Acesso total a todas as ordens  Aprovação, edição e exclusão de usuários  Impressão de ordens em formato A4 estilizado  Exportação de dados (CSV ou PDF)  Acompanhamento das etapas confirmadas  📱 10. Requisitos Técnicos Visual com TailwindCSS  Design responsivo para celular e computador  Funciona como PWA (instalável no celular)  Funciona offline com sincronização ao voltar à internet  Armazenamento com IndexedDB ou Firebase (simulado ou real)
